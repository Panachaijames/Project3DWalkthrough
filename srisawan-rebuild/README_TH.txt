SRISAWAN - ภาพแปลนใหม่ x01 / x02

1. เปิด Scene ว่างใน 3ds Max
2. Scripting > Run Script > Srisawan_New_Layouts_Quad.ms
3. กด BUILD BOTH FLOORS
4. ใช้ปุ่ม Show BOTH floors / FLOOR 1 / FLOOR 2 + VOIDS
5. Save As เป็น .max

สเกล: ช่องประตูลิฟต์ 1.20 เมตรเทียบ 19 พิกเซลใน x02
แกน X/Y อ้างอิง Lift Core; พื้นชั้น 2 +5.00 เมตร; ผนังสูง 4 เมตรทั้งสองชั้น
ผนัง: Editable Poly ชิ้นละ 6 หน้าสี่เหลี่ยม
พื้น: Editable Spline + Extrude; ชั้น 2 มี Void 2 จุดและช่อง core 6 ช่อง
ไม่มีเฟอร์นิเจอร์ ภูมิทัศน์ หรือรายละเอียดงานระบบ
ตั้ง Horizontal scale factor = 1.0 เพื่อใช้สเกลอ้างอิงประตูลิฟต์

ตรวจตัวเลขและภาพซ้อนกับแปลนแล้ว ยังไม่ได้รันทดสอบใน 3ds Max จริง
สคริปต์ตรวจพิกัดและ topology ขณะรัน หากตรวจไม่ผ่านจะหยุดพร้อมข้อความ
ความแม่นยำขึ้นกับภาพ raster; ไม่ใช่การถอดพิกัดจาก DWG
