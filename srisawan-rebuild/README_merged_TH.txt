SRISAWAN - สคริปต์ผนังแบบรวมชิ้น (REVISION 05 / merged walls)

ไฟล์: Srisawan_New_Layouts_Merged.ms
(ไฟล์เดิม Srisawan_New_Layouts_Quad.ms ยังอยู่ ไม่ได้แก้ไข)

วิธีใช้ (เหมือนเดิม)
1. เปิด Scene ว่างใน 3ds Max
2. Scripting > Run Script > Srisawan_New_Layouts_Merged.ms
3. กด BUILD BOTH FLOORS
4. ใช้ปุ่ม Show BOTH floors / FLOOR 1 / FLOOR 2 + VOIDS
5. Save As เป็น .max

สิ่งที่เปลี่ยน
- ผนังเป็นชิ้นเดียวต่อแนวผนังที่ต่อกัน (Editable Poly 1 ชิ้นต่อแนวผนัง) แทนกล่อง 1 ชิ้นต่อเส้นที่ถอดมา
- ไม่มีรอยต่อกลางผนัง และไม่มีสี่เหลี่ยมซ้อนกันที่มุมผนัง
- ผนังโค้งถูกปรับให้โค้งเรียบ และใส่ Smooth (Auto Smooth 40°) ผนังโค้งจึงเป็นผิวเดียว ส่วนมุมจริงยังคมเหมือนเดิม
- ชั้น 1: ผนังห้อง 65 แนว, Core 8, ผนังภายนอก 1, กระจก 6
- ชั้น 2: ผนังห้อง 83 แนว, Core 8, ผนังภายนอก 1, กระจก 7
- ชื่อวัตถุบอกโซน เช่น SR_L2_Partitions_East_Checkup_GI_012

เหมือนเดิม
- สเกลจากประตูลิฟต์ 1.20 ม. = 19 พิกเซล, พื้นชั้น 2 +5.00 ม., ผนังสูง 4 ม. ทั้งสองชั้น
- ความหนาผนัง: ผนังห้อง 0.18 / Core 0.24 / ผนังภายนอก 0.22 / กระจก 0.06 ม.
- พื้น Slab (Editable Spline + Extrude) ชั้น 2 มี Void 2 จุด และช่อง Core 6 ช่อง
- Layer, วัสดุ, จุดอ้างอิง SR_ORIGIN_LIFT_CORE และปุ่มตั้งค่าต่างๆ

การตรวจสอบ
- สคริปต์ตรวจผนังทุกชิ้นขณะสร้าง: เป็นวัตถุปิด (closed solid), ความสูงถูกต้อง, ตำแหน่งถูกต้อง
  หากไม่ผ่านจะหยุดพร้อมข้อความบอกชื่อผนัง
- ตรวจข้อมูลแล้ว: ขอบผนังห่างจากเส้นที่ถอดไม่เกิน 0.18 ม. และไม่มีผนังหายหรือยื่นเกิน
- ยังไม่ได้รันทดสอบใน 3ds Max จริง (เช่นเดียวกับสคริปต์เดิม)
- ความแม่นยำยังขึ้นกับภาพ raster ที่ใช้ถอด ไม่ใช่พิกัดจาก DWG
